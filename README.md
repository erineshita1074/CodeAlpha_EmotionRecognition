# Emotion Recognition from Speech - CodeAlpha ML Internship

## Objective
Recognize human emotions (happy, sad, angry, etc.) from speech audio.

## Dataset
RAVDESS Speech Dataset (8 emotion classes)
Source: https://zenodo.org/record/1188976

## Approach
Extracted MFCC (Mel-Frequency Cepstral Coefficients) features from audio,
trained a Dense Neural Network for 8-class emotion classification.
